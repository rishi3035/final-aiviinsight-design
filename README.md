## 🛠️ Local Development Guide

To run any design locally on your machine:

```bash
# 1. Clone this Master Repository
git clone https://github.com/rishi3035/AIVI-Master-Design-Suite.git
cd AIVI-Master-Design-Suite

# 2. Choose any design folder to run (e.g. Design 9 - Octolane)
cd design-9-octolane

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Open in your browser
# http://localhost:3000
```
